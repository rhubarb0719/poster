# 内容示例

> ⚠️ **当前三份均为测试内容**，用于验证不同文字量下的出图效果，未经品牌方确认。最终内容请按 [替换最终内容清单](../../docs/替换最终内容清单.md) 替换。

| 文件 | 档位 | 规则 |
|---|---|---|
| `简单.json` | 简单 | 短主标题 + 短副标题 + 3 个短卖点 |
| `中等.json` | 中等 | 中主标题 + 中英混排 + 1 个长卖点 |
| `压力.json` | 压力 | 长主标题 + 长副标题 + 5 个卖点 + 型号（测上限，不建议正式使用） |

字段：`主标题`、`副标题`、`产品`（外观描述，不印在图上）、`卖点`（列表）、`产品名`（可选，有产品图时填）。替换后先运行：

```bash
PYTHONPATH=src python3 -m poster check examples/content/*.json
```
