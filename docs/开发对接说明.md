# 开发对接说明

接口细节以 CR 平台 qwen-image-3.0-pro 官方接入文档为准；参考实现在 `src/poster/`。

## 流程

1. 内容 JSON + 风格配置 `styles/<id>/style.json` → `prompt.build_request()` 拼出请求体（每类随机项抽一项，自动跳过冲突组合）。
2. `POST /unified/v1/images/tasks`（无产品图）或 `/unified/v1/images/edit-tasks`（有产品图，1–3 张）。
3. 用返回的 `id` 循环 `GET /unified/v1/tasks/{id}/wait`，直到 `status` 为 `completed` / `failed`。
4. 读 `data[].url`，立即下载转存。

## 请求体

| 字段 | 值 | 能否改 |
|---|---|---|
| `model` | `qwen-image-3.0-pro` | 不改 |
| `prompt` / `negative_prompt` | 由 `build_request()` 生成 | 不手改；改文字改内容 JSON，改风格改 style.json |
| `aspect_ratio` / `quality` | `3:4` / `2K` | 不改 |
| `provider_options.prompt_extend` | `false` | 不改（开启会改写 prompt） |
| `seed` | 每张随机并记录 | 可改 |
| `n` | 1–6 | 可改 |
| `image` | 产品图 HTTPS URL 或 data URL | 有产品图时传，并改用编辑接口 |

## 内容 JSON

```json
{ "主标题": "大师全嵌 slot in", "副标题": "Slot-in Design", "产品": "一台博世全嵌入十字对开门冰箱，润玉白，玻璃门板，简约无把手设计", "卖点": ["Slot-in 全嵌", "抗指纹玻璃", "全嵌入设计，与橱柜齐平"] }
```

- 按 README「规则」写（中等难度、3 个卖点）。出图前运行 `python3 -m poster check <文件>`，有 `ERROR` 不出图。
- 有产品图时加 `"产品名": "冰箱"`：产品描述自动改为“参考图中的冰箱，保持外观不变”。

## 注意

- 并发 ≤3；任务 `failed` 且 `error.code = upstream_rate_limited` 时，等 10–30 秒重新提交（`cli.py` 的 `run_one` 已实现）。
- POST 带 `Idempotency-Key`，网络超时用同一个键重试，不重复扣费（`client.submit()`）。
- HTTP 200 也可能是失败，以正文 `status` 为准；查询必须用提交时的同一把 API Key。
- 保存响应头 `x-cr-usage-id` 用于核对费用。
- 模型偶尔写错字，上线前人工抽检。

## 新增风格

复制 `styles/_template/`，修改 `style.json` 的 `风格`、`options`（随机项）、`conflicts`（冲突组合，`{类别: 选项序号}` 全部命中即跳过）、`template`（拼接顺序）。
