# 替换最终内容清单

当前仓库里的文字（关键词库、内容示例）和样图都是**测试内容**。品牌方确认最终内容后（计划 2026-11-05 中午），按以下顺序替换。

## 1. 替换文字

- [ ] 用品牌方最终文字覆盖 [`examples/keywords/冰箱.json`](../examples/keywords/冰箱.json)，删除 `_状态` 那一行。
- [ ] 每张海报一个内容 JSON，放在 `examples/content/`（可删除测试用的 简单 / 中等 / 压力）。
- [ ] 文字里的引号用中文引号“”，不要用英文双引号。
- [ ] `产品` 只写外观描述，不写英文品牌名和型号；型号需要展示时放进 `卖点`。

## 2. 放入产品图（如有）

- [ ] 产品图放进 [`assets/products/`](../assets/products/)，命名规则见该目录 README。
- [ ] 对应内容 JSON 中填 `产品名`（例如 `冰箱`），产品描述会自动改为“保持参考图外观不变”。

## 3. 检查（不扣费）

```bash
export PYTHONPATH=src
```

```bash
python3 -m poster check examples/content/*.json
```

- `ERROR` 必须修改；`WARN` 表示错字或排版风险更高，按需调整（例如缩短文字、减少卖点）。
- 带产品图时加上 `--image assets/products/xxx.png`，会检查图片是否存在、数量是否超限。

预览 prompt：

```bash
python3 -m poster prompt --style style1-sticker --content examples/content/<文件>.json --random 1
```

## 4. 出图验证

```bash
python3 -m poster generate --style style1-sticker --content examples/content/<文件>.json --count 3
```

```bash
python3 -m poster generate --style style2-collage --content examples/content/<文件>.json --count 3
```

- [ ] 人工逐字检查：错字、漏字、重复、英文和型号是否原样。
- [ ] 产品外观是否与品牌方产品一致（用了参考图时尤其注意门体结构和颜色）。

## 5. 更新文档

- [ ] 两个风格 README 的“图片参考”换成最终内容的样图（现有样图标注为测试内容）。
- [ ] 提交并推送。
