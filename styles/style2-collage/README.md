# 风格2：杂志手账拼贴

**状态：调试中（v2）** · 配置文件：[`style.json`](style.json)

奶黄 + 米灰 + 黑的杂志手账拼贴：米灰网格纸作底，叠撕边纸、牛皮纸；奶黄色块压黑色超粗标题；卖点用纸胶带、便签、圆形色块和手绘箭头。**画风和配色固定**，底纸、标题与副标题处理、产品位置/大小/固定方式、卖点排布、点缀色和点缀**随机组合**。

## 参考图

- **主参考**：博世大师全嵌冰箱拼贴海报。借用米灰褶皱网格纸 + 点阵纸底、奶黄圆角色块双行标题、荧光黄绿描边副标题、圆形色块 + 方框 + 弧形箭头卖点、灰色撕边纸胶带卖点、焦糖棕胶囊贴纸 + 放射短线。
- **辅参考**：French Edge 拼贴海报。借用剪报拼字标题、图钉、回形针、带方孔的牛皮纸边、便签。
- **刻意不借**：两张图里的报纸印刷字、英文手写小字、页码、型号，这些是乱码的主要来源，v2 在文字约束里明确要求纸条一律空白。

## 请求参数

与风格1相同：`qwen-image-3.0-pro`，3:4，2K，`prompt_extend=false`，每张随机 seed 并记录。

## Prompt 结构

拼接顺序（每段一行）：① 风格 → 纸张底 → 标题（主标题 + 处理 + 大小；副标题 + 处理）→ 产品（内容 + 位置、大小、固定方式）→ 卖点（内容 + 排布）→ 点缀色、点缀 → ④ 文字约束。⑤ 单独放 `negative_prompt`。

### ① 固定风格

```
小红书竖版家电种草封面海报，3:4。视觉风格：杂志手账拼贴风，像把实物纸片贴在桌面上俯拍；配色固定为奶黄、米灰、黑三色，只允许极少量点缀色；素材模块为网格纸、撕边纸、牛皮纸、半透明纸胶带、便签、手绘箭头和圆形色块；纸张有真实的纤维纹理、撕边、轻微褶皱和柔和投影；主标题为黑色超粗黑体；辅助文字为黑色粗体；产品为高清抠图，正面平视，棚拍质感，边缘干净，有轻微投影；整体干净、有层次、留白适度，不杂乱，文字清晰准确，高清。
```

### ② 内容

同风格1：主标题、副标题、产品（外观描述，不写英文和型号）、3 个卖点，可选词见 [冰箱关键词库](../../examples/keywords/冰箱.json)；有产品参考图时加 `产品名`，产品描述自动换成：`参考图中的{产品名}，保持外观、颜色、门体结构和细节完全不变`。

### ③ 随机项（序号即 `--pick` 用的数字，按下列顺序）

**纸张底**（第 1 位）

1. 米灰色网格纸作底，叠一层撕边牛皮纸
2. 有轻微褶皱的米灰色网格纸作底，画面下方约三分之一换成浅灰色点阵纸，交界处为撕边
3. 米灰色网格纸作底，左侧露出一条带方形孔的牛皮纸边，像撕下的笔记本页
4. 米灰色网格纸作底，顶部斜压一条空白撕边白纸条，右下角叠一片牛皮纸

**标题处理**（第 2 位）

1. 主标题分成两行，每行压在一块独立的奶黄色圆角色块上
2. 主标题压在一条横贴的奶黄色宽纸胶带上
3. 主标题每个字剪成一块小方纸片拼贴，纸片为奶黄、白、牛皮纸色交错，字均为黑色
4. 主标题直接写在纸上，字的下半部压一道奶黄色马克笔高亮

**标题大小**（第 3 位）

1. 主标题字号很大，横向约占画面宽度85%
2. 主标题字号大，横向约占画面宽度70%，周围留白更多

**副标题处理**（第 4 位）

1. 副标题为倾斜的超粗字，填充点缀色，带黑色粗描边，像一枚贴纸，压在主标题下方
2. 副标题写在一张斜贴的小白便签上，上方用一段半透明胶带固定
3. 副标题写在一枚焦糖棕色胶囊形贴纸上，旁边有几道手绘放射短线

**产品位置**（第 5 位）

1. 产品居中
2. 产品略偏右
3. 产品略偏左
4. 产品居中偏下，底部略微出画

**产品大小**（第 6 位）

1. 产品约占画面高度55%
2. 产品约占画面高度65%
3. 产品约占画面高度75%，上端略压住标题色块

**产品固定方式**（第 7 位）

1. 产品顶部用一枚黑色图钉固定
2. 产品四角各贴一小段半透明胶带
3. 产品一角用一枚银色回形针夹住
4. 产品直接压在纸上，只有柔和投影

**卖点排布**（第 8 位）

1. 卖点混搭排布：第一个卖点写在奶黄色圆形色块里，外面套一个细黑方框，用手绘黑色弧形箭头指向产品；其余卖点写在斜贴的灰色撕边纸胶带上，散落在产品两侧
2. 每个卖点写在一条斜贴的半透明灰色纸胶带上，散落在产品两侧
3. 每个卖点写在一张小便签纸上，用胶带或回形针固定在产品周围
4. 卖点竖排成清单，写在一张撕边白纸上，每行前有一个手绘勾，纸片贴在产品旁
5. 每个卖点写在一块斜贴的奶黄色长方形标签上，散落在产品两侧

**点缀色**（第 9 位）

1. 荧光黄绿
2. 焦糖棕
3. 不加点缀色，只用奶黄

**点缀**（第 10 位）

1. 几道手绘放射短线和一个手绘星星
2. 一枚黑色图钉和一枚银色回形针
3. 一条手绘弧形箭头和几个小圆点
4. 无额外点缀，保持干净

**冲突规则**（同时命中即跳过）：

- 副标题处理1（副标题为倾斜的超粗字） + 点缀色3（不加点缀色）
- 卖点排布4（卖点竖排成清单） + 产品大小3（产品约占画面高度75%）
- 标题处理3（主标题每个字剪成一块小方纸片拼贴） + 标题大小1（主标题字号很大）

### ④ 文字约束

```
画面中只允许出现以下文字：主标题、副标题和卖点，每段文字只出现一次，字形清晰、完全准确，其中的英文、数字和型号按原样逐字写出。所有纸张、纸条、胶带、便签、贴纸上除指定文字外均为空白，不要出现报纸印刷字、杂志内文、英文小字、手写潦草字、页码、数字、型号、logo或任何伪文字。
```

### ⑤ 反向提示词

```
乱码, 伪文字, 报纸文字, 杂志内文, 印刷小字, 英文小字, 潦草手写字, 多余文字, 重复文字, 错别字, 模糊文字, 页码, 水印, logo, 产品变形, 透视歪斜, 卡通人物, 人物, 过度饱和, 霓虹色, 3D渲染, 杂乱堆砌, 低分辨率
```
