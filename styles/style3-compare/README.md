# 风格3：双产品对比图

版本 v2（调试中）· 配置 [`style.json`](style.json) · 参数：3:4、2K、`prompt_extend=false`

参考：两张博世洗烘套装对比封面（粗描边黄字标题 + VS + 手绘粗框；马克笔底纹标题 + 大号“2选1” + 对话框 + 箭头 + 星星 + 实景卡片 + 底部撕纸横幅）。**不使用型号和产品名称标签。**

## 内容

示例 [`examples/content/对比.json`](../../examples/content/对比.json)：

| 字段 | 规则 |
|---|---|
| 主标题 | ≤6 字 |
| 副标题 | ≤4 字，如“2选1” |
| 钩子 | ≤8 字，写在对话框或底部横幅上，如“一篇看懂怎么选” |
| 产品1 / 产品2 | 只写中文外观，不写型号 |
| 场景 | 可选，仅布局 1 用，默认“厨房一角” |

用产品实拍图时加 `"参考图": true`，按 左、右 顺序传 2 张图（`--image 图1 图2`）。

## 固定风格

```
小红书冰箱种草封面，双产品对比图风格，竖版3:4构图。手绘贴纸风：超粗黑体标题，搭配手绘箭头和小图案贴纸，可带一个对话框，画面丰富但不拥挤；画面分为顶部标题区、中部双产品区、底部收尾区；配色以黑、白、柠檬黄为主，红色只用于副标题和对比符号；摄影级写实产品与扁平手绘元素结合，高清。
```

拼接顺序：风格 → 背景 → 标题 → 钩子 → 产品 → 徽章 → 装饰（箭头 + 贴纸）→ 文字约束。

## 随机项（每类抽一项）

| 类别 | 选项 |
|---|---|
| 背景 | 1. 浅暖灰色纯色背景<br>2. 纯白背景<br>3. 米白色背景，带极淡的纸张纹理 |
| 标题处理 | 1. 柠檬黄色字填充细斜线纹理，黑色粗描边加黑色硬投影，像一枚大贴纸<br>2. 黑色字配白色描边，压在一道柠檬黄马克笔涂抹底纹上 |
| 副标题处理 | 1. 红色超大粗体，字号接近主标题，下方一条柠檬黄手绘下划线<br>2. 红色粗体配白色描边和黑色硬投影，略微倾斜，像一枚贴纸 |
| 钩子位置 | 1. 钩子"{钩子}"写在标题右侧的一个白色圆角对话框里，对话框黑色粗描边，尾巴指向产品；底部为一条很窄的柠檬黄撕纸边色带，色带上没有任何内容<br>2. 钩子"{钩子}"写在标题右侧的一个手绘云朵形对话框里，黑色细线描边；底部为一条很窄的柠檬黄撕纸边色带，色带上没有任何内容<br>3. 钩子"{钩子}"写在底部一条柠檬黄撕纸边横幅上，横幅两端各有一组黑色手绘括号短线；画面中不出现对话框 |
| 布局 | 1. 两款产品各放在一张等宽的浅色圆角卡片里，两张卡片左右并排，中间留一条白色细缝，卡片内背景为{场景}<br>2. 两款产品为纯白底抠图左右并排，每款产品外加一圈略带毛糙的手绘粗黑描边，两款产品正中间是一个红色粗体"VS"<br>3. 左右两列对比，每列外围一个手绘黑色细边框，框内背景留白 |
| 产品大小 | 1. 每款产品高度约占画面高度40%<br>2. 每款产品高度约占画面高度45%<br>3. 每款产品高度约占画面高度50% |
| 徽章样式 | 1. 黄色实心圆形，黑色粗体数字，细黑描边，贴纸感<br>2. 黑色圆角方块，白色粗体数字，带轻微纸张投影<br>3. 红色实心圆形，白色粗体数字，外圈白色描边<br>4. 柠檬黄五瓣花朵形，中心白色圆，黑色粗体数字<br>5. 橙色圆形，外围一圈放射状小短线，白色粗体数字 |
| 箭头 | 1. 一个黑色手绘弧形箭头，从标题区斜指向左侧产品<br>2. 一个黑色手绘弯曲虚线箭头，从标题区指向右侧产品<br>3. 两款产品上方一个黑色手绘双向弧形箭头，连接左右两侧<br>4. 两个短粗的黑色手绘箭头，分别指向两款产品 |
| 贴纸 | 1. 两个柠檬黄五角星和一个四角闪光<br>2. 一个红色爱心和两个柠檬黄小星星<br>3. 一个柠檬黄小皇冠和几道黑色放射短线<br>4. 一个柠檬黄圆形笑脸贴纸和一个四角闪光<br>5. 几个彩色小圆点和一条黑色手绘波浪线 |

- 布局 2 抽中时，文字约束自动加上“VS”。
- 防乱码：对话框里一定写钩子（不留空框）；钩子在底部横幅时不出现对话框；箭头 ≤2 个、贴纸 ≤3 个，均为纯图形。

## 文字约束

```
画面中只允许出现以下文字：主标题"{主标题}"、副标题"{副标题}"、钩子"{钩子}"、徽章数字"1"和"2"{额外文字}，每段文字只出现一次，字体粗大清晰、笔画完整，中文为简体。除这些指定文字外，不要出现任何其他文字、字母、数字、型号、产品名称、logo、水印或标签；对话框里只写钩子，没有内容的区域保持留白或只放纯图形。
```

## 反向提示词

```
乱码, 错别字, 多余文字, 小字, 英文小字, 手写字, 型号, 产品名称标签, 毛笔字标签, 产品铭牌文字, 控制面板文字, 显示屏数字, 价格, 水印, logo, 空白对话框, 多余的对话框, 多余的空白标签, 产品变形, 两款产品大小不一, 产品重叠, 画面拥挤, 低分辨率
```
