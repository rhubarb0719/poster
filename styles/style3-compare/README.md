# 风格3：双产品对比图

版本 v3（已定稿）· 配置 [`style.json`](style.json) · 参数：3:4、2K、`prompt_extend=false`

参考：两张博世洗烘套装对比封面（粗描边黄字标题 + VS + 手绘粗框；马克笔底纹标题 + 大号“2选1” + 对话框 + 箭头 + 星星 + 实景卡片 + 底部撕纸横幅）。**不使用型号和产品名称标签。**

## 内容

示例 [`examples/content/对比.json`](../../examples/content/对比.json)：

| 字段 | 规则 |
|---|---|
| 主标题 | ≤6 字 |
| 副标题 | ≤4 字，如“2选1” |
| 钩子 | ≤8 字，可写多句（列表），每张随机抽一句；写在对话框或底部横幅上 |
| 产品1 / 产品2 | 只写中文外观，不写型号和颜色；款式为十字对开门 |
| 场景 | 可选，仅布局 1 用，默认“厨房一角” |

用产品实拍图时加 `"参考图": true`，按 左、右 顺序传 2 张图（`--image 图1 图2`）。

## 固定风格

```
小红书冰箱种草封面，双产品对比图风格，竖版3:4构图。手绘贴纸风：超粗黑体标题，搭配手绘箭头和小图案贴纸，可带一个对话框，画面丰富但不拥挤；画面分为顶部标题区、中部双产品区、底部收尾区；标题颜色按“标题配色”，画面其余部分以黑、白为基础搭配少量柠檬黄，对比符号用红色；摄影级写实产品与扁平手绘元素结合，高清。
```

拼接顺序：风格 → 背景 → 标题（含标题配色）→ 钩子 → 产品 → 徽章 → 装饰（箭头 + 贴纸）→ 线条粗细 → 文字约束。

- 布局 2 抽中时，文字约束自动加上“VS”。
- 防乱码：对话框里一定写钩子（不留空框）；钩子在底部横幅时不出现对话框；箭头 ≤2 个、贴纸 ≤3 个，均为纯图形。

## 文字约束

```
画面中只允许出现以下文字：主标题"{主标题}"、副标题"{副标题}"、钩子"{钩子}"、徽章数字"1"和"2"{额外文字}，每段文字只出现一次，字体粗大清晰、笔画完整，中文为简体。除这些指定文字外，不要出现任何其他文字、字母、数字、型号、产品名称、logo、水印或标签；对话框里只写钩子，没有内容的区域保持留白或只放纯图形。
```

## 反向提示词

```
乱码, 错别字, 多余文字, 小字, 英文小字, 手写字, 型号, 产品名称标签, 毛笔字标签, 产品铭牌文字, 控制面板文字, 显示屏数字, 价格, 水印, logo, 空白对话框, 多余的对话框, 多余的空白标签, 产品变形, 两款产品大小不一, 产品重叠, 画面拥挤, 低分辨率
```
